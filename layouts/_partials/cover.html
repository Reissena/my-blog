{{- /* ===================================================================== 覆盖主题的 layouts/_partials/cover.html —— 只有文章详情页会用到它 （首页 / 列表页的卡片封面在 _partials/fluent_card.html 里自己渲染） 为什么覆盖：主题原版用 `resources.ByType "image" | GetMatch "**"` 去匹配资源，而 front matter 里写的是带前导斜杠的 "/images/posts/x.jpg"， 匹配不到就退化成 `absURL`，在预览的子路径下会指向线上域名（破图）。 这里与卡片用同一套解析逻辑： · assets/ 下的图 → 走资源管线（顺带发布到 /images/…），URL 兼容两种构建模式 · static/ 下的图（例如 Pages CMS 上传的）→ 直接用公开路径 · http(s) 外链 → 原样使用 样式用 .fc-post-cover（见 fluent.css），与整站圆角 / 描边一致。 入参沿用主题的 dict：{{ partial "cover.html" (dict "cxt" . "https://") -}} {{- $src = . -}} {{- else -}} {{- $path := strings.TrimPrefix "/" . -}} {{- with resources.Get $path -}} {{- $src = printf "%s%s" site.Home.RelPermalink (strings.TrimPrefix "/" .RelPermalink) -}} {{- /* 真实宽高写进属性：首屏大图加载完成前后高度一致，不会顶动正文 */ -}} {{- if eq .MediaType.MainType "image" -}} {{- $w = .Width -}} {{- $h = .Height -}} {{- end -}} {{- else -}} {{- $src = printf "%s%s" site.Home.RelPermalink $path -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
